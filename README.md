# RadhaMadhuram - Pure Traditional Indian Recipes

A premium, highly responsive recipe website called **RadhaMadhuram** ("Radha's Sweetness") featuring **16 recipes** across **4 categories** (Sweets, Breakfast, Lunch, Dinner). The site is built with a deep spiritual theme celebrating the Sanskrit motto:
> **"अन्नं हि पूर्णब्रह्म" (Annam Hi Purna Brahma)**  
> *(Food is indeed the Supreme Truth/Divine Consciousness)*

---

## ✨ Features

- **16 Authentic Recipes**: Under Sweets, Breakfast, Lunch, and Dinner (exactly 4 meals per category) with detailed ingredients, measurements, and cooking instructions.
- **Pure HTML & CSS Layout**: 
  - **CSS Category Tabs**: Powered by hidden `<input type="radio">` tags and sibling selectors. No JavaScript lag.
  - **CSS Target Modals**: Recipe details open in overlay windows using the CSS `:target` pseudo-class linked to URL hashes (`#`).
- **Interactive Checklists**: Ingredients list leverages native checkboxes with CSS sibling strike-through line decorations.
- **Premium Design System**: Luxurious warm-white background combined with golden/amber accents, modern typography (Cinzel & Playfair Display), responsive card grids, hover animations, and glassmorphic card elements.
- **Dark & Light Mode**: Seamless theme switching with local persistence (`localStorage`) using a tiny inline script.
- **High-Quality Visual Assets**: Custom-generated food photography and a matching circular brand logo representing Radha cooking in a traditional kitchen.

## 🚀 How to Run Locally

1. Clone this repository or download the files.
2. Open the directory on your computer.
3. Double-click the `radhamadhuram.html` file to open it in any web browser. No local server or build environment is required.

## 🧘‍♂️ Sanskrit Motto Meaning
The phrase **"अन्नं हि पूर्णब्रह्म" (Annam Hi Purna Brahma)** is a traditional Indian teaching meaning food is not just chemical fuel, but a divine gift that nourishes our physical structure and elevates our spiritual consciousness. Prepared with clean ingredients and cooked with love (Sattvik cooking), food is the source of health, peace, and joy.
